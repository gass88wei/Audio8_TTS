Audio8 TTS 本地一键包（Windows 64 位）
=======================================

一个便携的本地 TTS 合成工具，双击即用，无需安装，可整体拷贝到任意磁盘/电脑。

功能
----
- 文本转语音，11 种语言（中/英/粤/日/韩/法/德/意/西/荷/波）
- 零样本声音克隆：用一段 0.5-30 秒录音注册专属音色
- TUI 界面（终端操作，不占资源），另有命令行一键合成

使用步骤（首次）
----------------
1. 双击 启动TUI.bat
   - 自动检测 Python（需 3.11+，本机已装即用）
   - 首次运行自动安装依赖、下载模型（约 968 MiB，国内镜像，之后离线可用）
2. 按 Ctrl+N 注册音色：填写 wav 路径 + 该录音的原文 + 音色名
3. 选择音色 -> 输入文本 -> Ctrl+S 合成 -> 自动保存到 outputs/，可点播放试听

常用按键
--------
- Ctrl+N 注册新音色（声音克隆）
- Ctrl+R 刷新音色列表
- Ctrl+S 合成
- Ctrl+Q 退出

命令行快速合成
--------------
一键合成.bat "要合成的文字" 音色名

目录说明
--------
- model/  模型文件（首次运行自动下载，可整体复制到其他电脑复用）
- voices/ 已注册的音色
- outputs/ 生成的音频
- .venv/  Python 虚拟环境（自动创建）

其他说明
--------
- Apache-2.0 开源，代码与模型来自 github.com/Audio8-AI/Audio8_TTS
- 全部路径均为相对路径，整个文件夹可任意移动
- 删除 model/ 后可重新运行 启动TUI.bat 重新下载
